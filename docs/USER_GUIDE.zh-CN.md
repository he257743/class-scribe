# 听课译记

Mac 课堂实时英文转录与中文翻译。本机识别、本机翻译，无需 API 密钥。当前版本 1.6.2。

## 打开软件

双击“听课译记.app”。也可以把它复制到 Mac 的“应用程序”文件夹后使用。
软件要求 Apple 芯片 Mac、macOS 26 或更新版本。

本机开发版采用临时签名，未办理 Apple 公证。若系统拦截首次打开，请核对这是本次制作的副本，
再按系统提供的打开方式操作；无需关闭系统安全功能。

## 上课时使用

1. 首次点击“准备语言包”，联网下载系统英语语音包和中英翻译包。
   系统可能显示语言下载窗口。只有两类语言包都安装完成，“开始听课”才可用。
2. 点击“新建课堂”，输入课堂名称。点击右上角收音设置，可填写专业词、人名和缩写，逗号分隔。
   这些是识别提示，不能保证每个术语都能识别正确。
3. 点击“开始听课”，按系统提示允许麦克风访问。
   使用系统当前选择的输入设备，可在“系统设置 → 声音 → 输入”中切换。
4. 左侧显示英语原文，右侧显示中文机器翻译。默认按段合并并开启“实时中文预览”。
   英文与中文预览随讲述更新；识别文字停顿约 3 秒，或到达所选长度附近的定稿处，
   再用完整段落翻译定稿。标注“中文预览”的译文可能随上下文修订。
5. 中途可点击“暂停”，等待“正在暂停”结束；恢复时点击“继续听课”。快捷键 ⌘⇧P 可暂停或继续。
   下课时点击“停止听课”；如果已经暂停，点击旁边的“结束听课”。等待收尾完成后再关闭软件。
6. 停止后可以逐段点击铅笔修改文字，再从右上角导出 Word、文本或双语字幕。

## 中途暂停和继续

听课过程中点击底部“暂停”。软件会停止麦克风、保存已收进来的末尾文字，并显示
“已暂停 · 麦克风已停止”。暂停时间不计入课堂时长。已有文字的中文翻译仍可继续完成，
暂停期间也可以导出当前文字。

点击“继续听课”会恢复同一堂课，保留原文、译文和之前的录音，时间戳从累计听课时长接续。
每次继续会新增一个 CAF 原音文件，原来的录音不会被覆盖；暂停期间不会生成新的收音内容。
只保存文字模式也支持暂停和继续。

暂停期间会锁定这堂课。需要新建、切换或删除记录时，先点击“结束听课”。
退出软件会保存已有记录；重新打开后，可在左侧选回原课堂，再点击“开始／继续听课”。
软件不会因为重新打开而自动启用麦克风。

## 按段实时翻译

默认使用“按段翻译”并开启“实时中文预览”，默认段落目标为约 25 秒。
右上角设置中可选约 15、25、40 秒，可以关闭实时预览，也可以切换为“逐句翻译”。
设置在下次开始或继续听课时生效；已有段落和人工修改会保留。

段落尚未结束时，软件会用已经识别的英文生成中文预览，之后间隔约 1.5 秒尝试更新。
这是刷新节奏；实际显示延迟还包含语音识别、翻译和设备负载带来的耗时。
老师连续讲话时，预览仍会更新。英文继续增长时，会保留对应已有内容的中文预览；
如果识别纠正了前面的词，会替换不再对应的预览。更频繁的预览会增加本机翻译计算量。

识别文字停顿约 3 秒、且当前内容已识别定稿时，软件会把几句话作为同一个输入进行整段定稿翻译。
持续讲述时，优先在目标长度附近的句末分段；一直没有句末标点时，在约 1.5 倍目标长度后
的识别定稿处换段。长度是目标值，未定稿的识别结果可能需要继续等待。
这个划分依据识别时间和停顿，不保证恰好等于老师讲完一个知识点或自然段。

点击“停止听课”会补上剩余段落的翻译；若识别未能完全定稿，仍保留草稿和回听提示。
若在整段翻译完成前导出，现有中文会标注“中文预览，待整段定稿”。
合段只拼接识别原文，不对英文做摘要或改写。JSON 记录还保留每个原始识别片段的文字、
时间范围与置信度，以及中文预览所对应的英文快照，方便之后核对。
重新打开软件后，已保存但尚未完成整段翻译的内容会继续尝试翻译。

## 删除课堂记录

右键左侧要删除的课堂，选择“删除课堂…”，或选中课堂后点击右上角废纸篓按钮。
确认窗口会显示课堂名称；点击“移到废纸篓”后，该课堂的文字和关联原音一起移出列表。
取消确认不会修改记录。已经导出的 Word、TXT、SRT 不会删除。

开启麦克风、正在听课、暂停中和末段收尾期间均不能删除，需先停止或结束课堂并等待收尾完成。
删除最后一条后，列表保持为空；点击“新建课堂”再开始记录。

记录与原音会打包到废纸篓中的“待删除课堂-…”文件夹。需要恢复时，先退出软件，
从废纸篓找回该文件夹，把里面“记录”中的 JSON 放回本机保存目录的“记录”，
把“录音”中的 CAF 放回保存目录的“录音”，再重新打开软件。清空废纸篓后无法通过本软件恢复。
如果移动到废纸篓失败，软件会尝试把文件放回原处并显示错误，课堂仍留在列表中。

## 选择识别引擎

右上角设置中的“英语识别引擎”提供苹果连续识别和千问 Qwen3-ASR。停止听课后切换；暂停期间仍保留当前引擎，结束课堂后才能更改。

选择千问后，首次点击“准备千问识别”。需要下载约 25MB Python 运行环境、MLX 等配套组件和约 1.6GB 识别权重。准备可以取消、重试。组件保存在 Mac 本机，安装后日常运行不依赖源码或 T7。

看到“正在听课”后再开始讲述。千问首次开始需要加载模型，随后约每 3 秒尝试提交一次音频快照；通过语音活动检查后才进行识别。停顿或最长约 12 秒的音频窗口结束后定稿。完成时间取决于本机负载，3 秒不是端到端延迟承诺。千问片段时间为音频窗口范围，不是逐字对齐。

安静或只有底噪时应保持等待，不会把术语提示当作字幕。若声音太轻或太短，语音检测也可能漏判；请靠近声源并保留原音核对。

千问负责英语识别，中文仍由苹果模型翻译。这个约 1.6GB 的语音识别模型与约 1.4GB 的 Qwen3 文字校对模型不同。两者可以同时开启，但会增加资源使用。

若出现处理积压或末段未完成提示，请保留原音回听核对；不要把“已定稿”当作百分之百正确。苹果与千问均保留同一套暂停、保存和导出功能。

## 旧记录出现大量术语列表时

1.6.0 的千问识别存在提示回显缺陷，可能把内部词表反复显示为原文。1.6.1 会将符合该特征的段落标为“识别异常”，折叠显示，并停止把它们当作课堂内容继续翻译。

异常原文和旧机器译文仍可展开查看，录音不会删除。请根据原音核对；停止听课后可用编辑按钮填写确认的内容。Word / TXT 导出将异常原文放在核查标签下，字幕保留时间范围并提示回听。

升级后首次使用千问时，如提示准备组件，请再次准备；会补充语音检测组件，复用已校验的模型。此后重新开始听课即可。

## 原文和中文反复刷同一句话时

这是识别异常。语音活动检测只能判断音频像不像人声，无法保证识别器正确生成文字。1.6.2 会检查极端循环及生成上限，将可疑窗口标为待回听，保留原文，不再把它继续翻译成大段重复中文。

后续正常讲话可继续识别。同一窗口补充更多声音后若识别恢复，可靠草稿可替换异常草稿；未恢复的异常片段会随记录保存。普通重复强调不会被直接删除，人工核对后的编辑内容仍优先。

千问模式现在等待一次音频快照识别完成并通过检查后再更新草稿，中文显示可能比逐词流式输出多等一会儿。软件仍不能保证所有含混声音都识别正确；请保持清楚的英语收音并保留原音。

## 专业词与后文校对

在右上角设置中选择课程领域，可使用操作系统、计算机网络、软件工程或综合计算机术语表。也可补充术语提示，使用逗号或换行分隔，或者写成 `mutex=互斥锁`。苹果识别的提示在下次开始或继续听课时生效；千问模式不注入识别指令或完整词表，术语用于后文校对。

开启“结合后文校对术语和译文”，选择轻量或较大上下文模型，再点击“准备上下文模型”。首次额外下载约 187MB 运行组件和约 523MB / 1.4GB 模型；可以取消准备，之后重试。较大模型会增加内存和发热。

基础识别与翻译不需要这个额外模型。准备好后，软件在后台回看最近约 90 秒、最多 4 段识别文字，尝试根据后文引用修正专业词或中文词义。默认约 8 秒的请求节流只是调度间隔，不是每次校订的完成时间。

校订结果带有“上下文校订”标记，可以展开查看原始英文、初始译文、依据和后文原句。AI 不会覆盖原始识别数据；停止听课后，可选择“使用原始识别”或人工编辑，人工确认的内容不会再被自动校订覆盖。

Word 和文本导出包含校订、原始识别与依据；字幕使用校订显示内容，并标注上下文校订。关闭校对会停止新的请求，已保存的校订仍可查看或恢复。

这个功能根据文字推断，不重新听原音，也不能保证像真人一样理解整堂课。词表之外、与原音拼写差异较大或无法对齐原译文的错误可能不会修正。模型可能漏改或误判；涉及引用、数字、否定和专业概念时，仍以原音核对为准。

## 本机保存位置

每次定稿和翻译完成会自动保存；收音期间每五秒保留一次记录快照。
意外关闭后，软件启动时会加载已保存记录；未完成的翻译可以重试。
此功能不能保证保存突然断电前尚未写入的最后几秒。

默认保存原音，便于回听。可以在右上角收音设置中关闭“保留原音”。
原音为单声道或系统兼容声道的 16 位 PCM CAF 文件，通常可直接用 QuickTime 播放。
录音按每次“开始/继续”分文件保存，课堂文字的时间戳会连续累计。

点左下角“打开保存文件夹”可以找到全部数据：

`~/Library/Application Support/ClassScribe`

- “记录”保存课堂 JSON，包含原文、译文、时间戳和关联录音信息。
- “录音”保存 CAF 原音。
- “ContextRuntime”和“ContextModels”保存可选上下文组件与模型。
- “QwenASR”保存可选语音识别组件与模型；以上目录位于 Mac 本机，移动源码目录不会自动迁移它们。
- 导出的 Word、TXT、SRT 保存到你在保存窗口选择的位置，可选择外接硬盘。

把软件放在外接硬盘 不会自动把上述记录目录迁到外接硬盘。请定期导出或备份原音与记录。
如果从外接硬盘运行软件，使用期间保持硬盘连接。

## 识别与翻译的范围

软件使用 Apple SpeechAnalyzer 与 SpeechTranscriber 识别英语，用 Apple Translation 翻译为简体中文。
语言包安装后，两项处理都在设备端完成。可选上下文校对使用本机 Qwen3 模型，仅通过本机回环地址接收最近文字；没有云端推理回退逻辑。
系统语言包下载及系统本身的联网行为仍由 macOS 管理。

当前版本针对英语授课设计，不支持自动切换为中文听写、不区分说话人，也不采集电脑内录声音。
英文原文和中文译文均可能有误，尤其是远距离收音、口音、人名、数字和专业术语。
“建议回听”由低置信度或尚未定稿状态触发，未出现标记也不代表文字一定正确。
本地合成语音测试中，mutex 就曾被识别成 mute X。请结合原音核对需要准确引用的内容。

## 常见情况

- **没有文字或音量显示不动**：确认系统输入设备正确，并在“隐私与安全性 → 麦克风”中允许本软件。
- **译文显示待译或失败**：确认语言包就绪，点击“重试翻译”。原文会保留。
- **显示保存失败**：先导出文字，再检查电脑剩余空间和保存文件夹权限。
- **处理跟不上**：软件会提示并停止，避免静默丢弃识别输入。关闭其他高负载程序后继续，必要时回听原音。
- **发热**：实时识别和翻译需要持续计算，不能保证电脑不发热。软件仅更新必要的译文并在停止后释放语音模型。
- **想先看效果**：帮助菜单中选择“查看演示文字”。演示会明确标注，不会开启麦克风或写入真实课堂记录。

## 源码与验证

源码在同目录 `Sources`，可用 Xcode 命令行工具运行 `build.sh` 重新构建。
运行 `Tests/run.sh` 可检查时间轴、重复去重、翻译覆盖保护、保存恢复、导出格式，
以及删除取消、关联录音归档、失败回滚、录音保护、空列表重启、段落缓冲、停顿分段、
停止补译、旧记录兼容、逐句模式切换，以及连续发言的中文预览、请求合并、晚到译文保护和取消恢复。
暂停检查使用可控的测试录音后端与时钟，验证暂停停止收音、计时排除暂停间隔、继续录音衔接、
启动失败恢复和退出时保存末段；不因此启用真实麦克风。
`Tests/NativeEngineTest.swift` 使用合成英语文件验证实际本机识别与翻译，报告保存在 `build`。
`Tests/NativeParagraphTest.swift` 验证合成英语经过实际识别、应用段落队列、本机翻译和保存恢复。
运行 `zsh Tests/run-native.sh` 可验证本机中文预览、整段定稿及合成英语识别流程，需要已安装系统语言包。
中文预览耗时报告从输入识别文字开始计时，未包括麦克风和语音识别本身的耗时。
测试语音不是课堂远场录音，不代表已完成真实教室的准确率或长时间稳定性测试。
